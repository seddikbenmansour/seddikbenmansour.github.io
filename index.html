Projets IA en production

Pipeline d'agents IA — Analyse de campagnes de tests

Pipeline multi-agents pour l'analyse automatisée des logs de campagnes de tests (fichiers ~100 Mo), avec pré-analyse locale (sans LLM) en ~30 secondes et déduplication intelligente des erreurs.

  • Triage automatique par criticité, analyse approfondie des erreurs, détection de patterns cross-campagnes
  • Architecture hybride : Ollama (local, données sensibles) + Google Cloud Vertex AI (Claude Sonnet, Gemini)
  • Garde-fous anti-hallucination (vérification déterministe du code proposé par le LLM)
  • Étude d'évolution vers une architecture RAG (recherche vectorielle sur le code et la documentation)

Agent IA — Résolution XPath IHM

Agent connecté en direct au navigateur réel via un serveur MCP Playwright, pour l'inspection du DOM en direct et la correction automatique des XPaths cassés suite aux refontes d'interface web.

  • Supprime la recherche manuelle des XPaths, sécurise la maintenance des scripts de test
  • Savoir-faire formalisé en Skills Copilot réutilisables (authentification IHM, inspection DOM)
  • Adopté par l'ensemble de l'équipe MDB
